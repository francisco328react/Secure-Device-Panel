🔐 Secure Device Panel

Dashboard web para gerenciamento e segurança de dispositivos, inspirado em sistemas de MDM (Mobile Device Management).
Projeto desenvolvido como portfólio profissional para vagas de Desenvolvedor Frontend React.

---

🚀 Tecnologias

* **React 18 + TypeScript**
* **Vite**
* **TailwindCSS**
* **React Hook Form + Zod**
* **React Router DOM**
* **i18next (PT / EN)**
* **Axios**
* **Context API**
* **ESLint + Prettier**

---

🧠 Funcionalidades

* **Autenticação e rotas protegidas**
* **Controle de permissões por perfil (admin / user)**
* **Dashboard de dispositivos**
* **Ações de segurança (bloquear, desbloquear, reset)**
* **Sistema de auditoria (logs)**
* **Formulário com validação tipada**
* **Internacionalização (Português / Inglês)**
* **UI responsiva**
